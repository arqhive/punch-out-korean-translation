# v1.0f

첫 공개 완성판입니다.

## 적용 방법

1. `R7PJ_KPatch_v1.0f.zip`을 받아 압축을 풉니다.
2. 일본판 원본 이미지(`R7PJ01`, ISO 또는 WBFS)를 `패치하기.bat` 위에 끌어다 놓습니다.
3. 원본과 같은 폴더에 `Punch-Out!! (Korean) [R7PJ01]`이 생깁니다.

지원 형식: ISO→ISO, WBFS→WBFS, CISO·WIA·WDF→ISO. RVZ·NKit는 ISO로 바꾼 뒤 적용합니다.

## 바뀐 점

- 메뉴, 닥 루이스의 조언·응원 대사, 트레이닝 자막, 튜토리얼, 선수 소개·도전 과제, 갤러리·영상 설명, 밸런스 Wii 보드 안내, 세이브·오류 메시지를 한글화했습니다.
- 타이틀 로고, 포스터, 손목 스트랩 안내 화면, HOME 메뉴, Wii 메뉴 채널 이름·배너, 영상 속 로고 글씨를 한글화했습니다.
