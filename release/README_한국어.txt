펀치아웃!! 한글패치 v1.0f (Wii / 일본판 기준)
============================================================

■ 준비물
  - 일본판 디스크 이미지 (게임 ID R7PJ01, Rev 1)
  - Windows 10 이상 (따로 설치할 프로그램은 없습니다)
  - 빈 공간 약 10GB (풀어 둔 파일 약 3GB + 결과 이미지)

■ 지원 형식
  원본                                   결과
  ISO (정본 덤프, WBFS에서 변환한 ISO)   → ISO
  WBFS                                   → WBFS
  CISO, WIA, WDF                         → ISO
  RVZ   ×  Dolphin에서 ISO로 변환한 뒤 적용
  NKit  ×  NKit 도구로 원본 ISO로 복원한 뒤 적용

  덤프·변환 방법에 따라 MD5가 달라도 게임 파일만 같으면 적용됩니다.
  북미판·유럽판에는 적용할 수 없습니다. 일본판 Rev 1로 확인했습니다.

■ 적용 방법
  1) 압축을 풉니다.
  2) 원본 이미지(ISO 또는 WBFS)를 "패치하기.bat" 위에 끌어다 놓습니다.
     - 원본을 이 폴더에 넣고 "패치하기.bat"을 더블클릭해도 됩니다.
     - 이미지가 여러 개 있으면 경로를 물어봅니다. 파일을 창에 끌어다 놓고 Enter.
  3) "완료"가 나올 때까지 기다립니다(1~3분). 진행 중에는 창을 닫지 마세요.
  4) 원본과 같은 폴더에 결과 파일이 생깁니다. 원본은 바뀌지 않습니다.
       ISO 원본  → Punch-Out!! (Korean) [R7PJ01].iso
       WBFS 원본 → Punch-Out!! (Korean) [R7PJ01].wbfs

  ※ 결과 형식 바꾸기 (예: ISO 원본 → WBFS 결과)
     이 폴더에서 PowerShell을 열고 결과 파일 확장자를 지정합니다.
       powershell -ExecutionPolicy Bypass -File patch.ps1 "원본.iso" "결과.wbfs"

  ※ 결과 파일의 MD5는 원본에 따라 달라질 수 있습니다. 게임 내용은 같습니다.

■ 실행 방법
  - Dolphin: 결과 ISO나 WBFS를 게임 목록 폴더에 넣거나 직접 엽니다.
  - Wii·Wii U vWii (USB Loader GX): WBFS를 권합니다.
      wbfs/Punch-Out!! (Korean) [R7PJ01]/R7PJ01.wbfs
    처럼 넣습니다.

■ 오류가 날 때
  - "… (R7PJ01)가 아닙니다": 북미판·유럽판이거나 다른 게임입니다.
  - "원본 게임 파일이 다릅니다": 이미 패치한 이미지거나 손상된 덤프입니다.
  - "RVZ는 지원하지 않습니다": Dolphin 게임 목록에서 우클릭 → 파일 변환 → ISO.
  - "wit.exe 실행 실패": 빈 공간이 모자라거나 원본 파일이 손상됐습니다.

■ 한글화 범위
  - 텍스트: 메뉴, 닥 루이스의 조언·응원 대사, 트레이닝 자막, 튜토리얼, 선수 소개·도전 과제,
            갤러리·영상 설명, 밸런스 Wii 보드 안내, 세이브·오류 메시지
  - 그래픽: 타이틀 로고, 포스터, 손목 스트랩 안내 화면, HOME 메뉴
  - 영상: 튜토리얼·데모·인트로 영상 속 로고의 「パンチアウト!!」 글씨
  - 글꼴: G마켓 산스 (한글·숫자·영문·기호)
  - Wii 메뉴 채널 이름·배너
  - 원작에서도 영어인 문구(PRESS START, KO, 엔딩 크레딧 등)는 영어 그대로 두었습니다.

■ 확인 환경
  - Dolphin 에뮬레이터
  - Wii U vWii (USB Loader GX)

■ 알려진 문제
  - 실기(Wii·Wii U vWii)에서 메뉴를 뺀 대사·안내 글씨의 테두리가 조금 흐리게 보입니다.
    일본어 원판도 똑같이 흐립니다. 이 게임은 글자를 큰 그림으로 만들어 두고 화면에 그릴 때
    약 0.6배로 줄여 그리는데, 실기는 이때 픽셀을 섞어 줄이기 때문에 테두리가 번져 보입니다.
    Dolphin에서 내부 해상도를 높이면 또렷하게 보입니다.
